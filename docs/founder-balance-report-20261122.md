## 問題点（優先度順）
1. **致命的：岩場で繁殖がほぼ成立しない。** 岩場適応1.0でも11/11絶滅。種補充も8/8絶滅。岩場の地衣類・採食条件・初期繁殖可能性を一体で検証。
2. **初期戦略と経済の不均衡。** 草原の産卵数4→8は基準の遺伝子ポイント2.8のまま（追加費用0）だが、独立8 seedでスコア11755→13419。省エネ1.0はポイント+4で14210。単為生殖は追加8ptなのに3939。能力費用と生存戦略の強さが一致しない。
3. **開始時の詰み。** 肉食1.0は11/11絶滅。ランダム初期能力は初回4地形×3seedで12/12絶滅。フィールド選択前に「地形適合」「食料種別」「繁殖成立見込み」を事前警告する。ランダム生成は配置可能な生息型の保証が必要。
4. **多産・過密・発見スコアの歪み。** 産卵数8は独立8 seedで平均673体出生、総計4,800件の「飢餓・栄養不足」扱い死亡。新種発見数も標準28.5→32.8。持続型でなく大量出生型が高得点を得やすいかを継続検証。
5. **介入の戦略性不足。** 初回3seedの草原型に150stepごと資源補充で平均終了個体数17→45.7、乾燥型10.7→25.3。一方、岩場では種補充が無効。ゲーム内に資源不足サインと介入の効果見込みを表示したい。
6. **死亡診断の粗さ。** `vitalDeathCause` はHP損失原因のfallbackを「飢餓・栄養不足」にまとめる。記録上の大量死亡は原因の細分化（純粋な資源不足、採食失敗、過密、温度適応不足）が必要。感染抵抗力最大の増分利益も限定的でポイント価格の再検討候補。
7. **地点×プリセットの相性説明不足。** 3seedの池では陸生草原型3/3即絶滅（平均43 step）、岩場型も3/3即絶滅。移入前に適合度とリスクを予告すべき。

## 提案する実装順
1. 岩場型の最低限の採食・繁殖ループを成立させる。効果判定は新規seedで適地岩場型の生存率と世代進行、介入前後差分。
2. 遺伝子ポイントを実測に基づいて再価格付け。産卵数に非線形のコストを導入し、単為生殖のコスト/能力を見直す。弱点によるポイント還元の仕組みは維持。
3. 初期能力選択時に想定適地と「水辺/陸地適合・食料・温度」の警告を出す。ランダム生成に「ランダムな戦略」と「配置に合うランダム」を区別。
4. 生存期間に加え、同一種の継続世代・資源を残しての繁殖・定着を評価するようスコアを見直す。
5. 介入選択画面に「何が原因で弱っているか」「何をすれば改善するか」を可視化。

**注意**: 3 seed の傾向は偏りが大きいため、8 seedの独立再検証を判断の軸にする。成功/失敗率の厳密な信頼区間や人間プレイでのUI操作検証は未実施。ゲーム本体のコード・スコア・ポイント配分はこの調査では変更していない。
