# Edenomaly 遺伝子パラメータ感度スクリーニング（2026-11-23）

## 結論

**今回の実験で「全条件で出力が不変の死にパラメータ」は0/26。** ただし、これは「すべてがゲームとして必要」や「すべての機能が発動した」という証明ではない。遺伝子の変更が形態や乱数系列を変え、間接的に結果を変える場合もある。

- 実行: GitHub Actions [Founder gene sensitivity audit](https://github.com/memem47/Edenomaly/actions/runs/45096776518)（成功）
- 対象: 26遺伝子、レベル1対10
- 条件: 草地・水場・乾燥地、それぞれ固定2シード（7201,7202）
- 期間: 各600ステップ
- 318試行（26項目×2値×3地形×2シード + 対照6試行）
- 基本操作: 同一シードと移入地点を用い、初期遺伝子の該当1項目だけ変更。実際の `Ecosystem.step()` で計算する
- 出力: 個体数の時間積分（個体・ステップ）、生存期間、ピーク個体数、出生・死亡・交配・感染・水草植え付け・世代・エネルギーなど

## 次に精査するべきもの

1. **水草栽培は削除しない**。水場で明確に利用されている。陸地では項目を非表示にするなど条件付き表示が合理的。
2. **巣作りと産卵地選択**は機能の重複がある（巣作りは産卵時の行動、産卵地選択は候補地探索）。統合するならコードの仕様を一つにまとめてから再試験する。
3. **警戒心と捕食者の識別**は逃走確率計算の別因子。統合すると「恐れやすいが識別下手」の個性がなくなる。
4. **分散傾向と集合傾向**は密集回避と仲間への接近の別因子。単純な1軸化は戦略の自由度を下げる。
5. **幼体の共食い・親の給餌**は条件付き発動。行動イベント発生数、親子の生存率、エネルギー授受を直接測る追加実験が必要。
6. **岩場適応**は岩場スタートを含めていないため、その本来の環境での強さは未評価。**適温・休眠・温度耐性**は複数季節で再評価が必要。

## 判定の限界

- シードは2個/地形、600ステップのみ。長期・レア発動を保証しない。
- `editFounderGenome()` は `deriveFunctionalBody()` も計算するため、遺伝子を変えると見た目だけでなく体格・目・口・顎などが連動する場合がある。
- 初期の6つの対照試行を含めて318試行。繁殖/感染などは確率的で、同じ初期シードでも途中の乱数呼び出し系列が分岐する。
- 「効果が出た」ことは「固有の必要な能力」とは限らない。機能重複を確認するには相関と複数因子試験が必要。
- この段階では**遺伝子削除は行わず**、すでに実装した「詳細能力」折りたたみを維持する。
