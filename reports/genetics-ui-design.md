# Edenomaly 遺伝子編集と基本ステータス設計

## 実装済み — 全37遺伝子の透明化（2026-11-23）

- [x] シミュレーションに継承される37遺伝子全件を `FOUNDER_FIELDS` に登録し、1–10段階で編集
- [x] 「通常編集（19項目）」と「全37遺伝子を表示（追加18項目）」に分離。詳細項目も削除せず編集可能
- [x] すべての編集可能な遺伝子に外観表現を割当
  - 26の生態・繁殖・行動遺伝子：体色、皮膜、口元、栄養粒、尾びれ、硬い突起、模様、内側の光、眉などへ反映
  - 5つの体格・形態遺伝子（`r/elongation/eyes/mouths/jaw`）：体格・形状・目・口・顎へ直接反映
  - 4つの外観遺伝子（`tailLength/hornLength/antennaLength/pattern`）：実際の尾・角・触角・斑点へ反映
  - `albino`：白化の体色表現、`longevity`：体内光沢
- [x] 体格・目・口・顎は通常、機能的能力から `deriveFunctionalBody` によって自動決定。**手動で編集した項目だけ** `bodyOverrides` として固定して遺伝させる
- [x] `functionalOrnaments` は生態上の速度・維持エネルギーなどに関わる従来仕様を保持し、`visibleOrnaments` は外観遺伝子と機能表現の両方から描画/種名を導出。二重の独立外観データは作らない
- [x] 遺伝子を編集しても二倍体の対立遺伝子と子孫の変異・交雑処理が整合
- [x] 37遺伝子の網羅・可視化・編集・遺伝について自動テスト追加

### 注意

- 37遺伝子が**すべて生存能力を上げるという意味ではない**。`albino` と旧 `longevity` は外観形質。
- 旧寿命遺伝子 `longevity` は寿命減少に使われていないため、「体内光沢」として扱う。寿命の自動減算は復活させない。
- 生態・繁殖・行動遺伝子の一部は複数の外観チャネルへ合成される。細かな1段階の変更が、いつでも肉眼で明確に分かるとは限らない。
- 二倍体の二つの対立遺伝子は内部情報として保有。編集は表現値を指定して2コピーを同値にする方式。将来の「対立遺伝子直接編集」は別の実験モードで検討。
- 外観形質により種族の分類名が変わる場合がある。形態の違いが分類を変えるのは意図通り。

## 次段階（提案） — 基本ステータス6種類＋スキル

プレイヤー用の操作を**基本ステータス6種類 × 1～10段階＋生存戦略／スキル**へ整理し、37遺伝子を「遺伝子研究／詳細編集」へ格納する。

| 基本ステータス | 主な遺伝子（連動先） | 主なプレイ効果 |
|---|---|---|
| ちから | `jaw,retaliation,diet,guard` | 攻撃・反撃・捕食 |
| すばやさ | `dispersal,elongation,eyes` | 移動、方向転換、探索 |
| たいりょく | `r,resist,frugality,tempTolerance` | HP・感染抵抗・維持コスト |
| かしこさ | `predatorSense,nestChoice,caution` | 危険の識別、巣の選択 |
| かんきょうてきおう | `wet,dry,rock,idealTemp` | 地形・気温への適応 |
| はんしょくりょく | `brood,shell,guard,parentFeeding,yolkReserve` | 産卵と子育て |

**スキルは新しい独立遺伝子として追加しない。** 内部37遺伝子と環境条件から発動する行動として扱う。たとえば `waterGardening` と `aquatic` が一定条件を満たす個体で「水草栽培」、`juvenileCannibalism` と食性・空腹で「幼体共食い」、`hibernate` と季節条件で「休眠」。

重要な独立した戦略（陸生／水生、草食／肉食、雌雄異体／雌雄同体／単為生殖、擬態、集合傾向）は基本ステータスの単純な上下関係にしない。「プレイスタイル/特性」として選択できるようにする。

### 避けるべき設計

- 「すばやさ」を上げるだけで無条件に体格も大きくなる、という不自然な一律のバフ
- 基本能力と37遺伝子が別々に存在し、値が食い違う二重管理
- 基本能力が高い個体が必ず有利になり、進化のトレードオフや予想外の戦略が失われる構造
- 既存の遺伝子を急に削除して、旧リプレイや生態系ログとの互換性を破壊する変更

### 次段階の推奨実装順

1. `basicStats(genome)` を**派生表示**として追加。6項目の値は37遺伝子から算出し、まだ生態式を変更しない。
2. 6項目を編集すると関連する遺伝子セットを同時調整する「簡易編集モード」を追加し、詳細編集で個別に微調整できるようにする。
3. スキル一覧に発動条件と実際の発動回数を追加。条件付きの死にスキルを可視化する。
4. 生存率・繁殖・形態多様性・一種支配・ゲームスコアを比較し、基本能力へ移行しても発見の面白さが維持できるか検証する。
